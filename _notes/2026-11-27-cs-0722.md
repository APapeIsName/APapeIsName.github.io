앞서 공부했던 sed가 파일 편집에 초점을 뒀다면 awk 는 파일 파싱에 초점을 둔다. 특히, sed처럼 프로그래밍 언어로써도 사용할 수 있다. awk의 문법에 대해 공부하진 않을 테지만 가벼운 문법만 다루고 가자. 

```
awk '{print $2}' text.txt
```

text 에는 3x3 매트릭스 형태의 abcdefghi 가 저장돼 있다. 구분자는 띄어쓰기이다.

```
a b c
d e f
g h i
```

awk는 파일 파싱을 지원하는데, 파싱이라는 것은 언어의 규칙을 통해 문장을 분석하는 과정이다. "나는 밥을 먹었다"를 파싱할 때 그 기준점을 띄어쓰기로 한다면 "나는", "밥을", "먹었다" 라고 구분할 수 있다. 이처럼 문장 내 규칙을 분석하는 것을 파싱이라고 한다. 

본론으로 돌아가서 awk의 문법에서 중요한 것은 따옴표 안에 있는 내용이다. '{ 는 문법을 시작하겠다는 의미이고, }'는 닫는다는 뜻이다. 그 안에 들어간 print는 출력한다는 뜻, $2는 2번째 것에 대한 의미이다. 그리고 뒤에 text.txt 는 대상 파일이다. 여기서 구분 기준이 정해지지 않았는데, 이의 경우 공백으로 처리한다. 따라서, 우리는 결과 값으로 `b\n e\n h\n` 가 나오는 걸 볼 수 있다. 

만약 구분 기준을 정하고 싶다면 -F를 사용하면 된다.

```
awk -F, '{print $2}' text.txt
```
이렇게 작성하게 된다면 공백으로 3줄이 나타난다. 공백으로 3줄이 나타나게 되는 이유는 파싱 기준을 콤마로 변경했고, text.txt는 콤마를 사용하지 않았으므로 abcdefghi가 1번째 열, 공백이 2번째 열로 나타나게 된다. 따라서 $2를 $1로 바꾸면 3x3의 매트릭스 형태를 가진 abcdefghi가 나타난다.

이제 여러 셸 명령어, 즉 프로그램들을 조합해보자.
