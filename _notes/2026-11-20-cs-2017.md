우리는 터미널을 열어서 명령을 칠 수 있다. 보통 이럴 때 쓰는 언어를 셸 언어라고 표현하는데, 셸 언어란 것은 bash, zsh, powershell 등 다양하게 존재한다. 강의에서는 bash, zsh를 다룬다. 
먼저 다룬 내용은 **date** 다. date 는 간단하게 쳐볼 수 있는 명령어로, 입력 후 엔터를 치면 현재 시간이 나온다. date 처럼 단순히 입력 후 끝나는 게 있는가 하면 인자를 받아서 처리할 수 있는 명령어도 있다. 대표적으로 나온 예시가 **echo**이다. 

echo는 터미널에 문자열을 출력할 수 있다. 이때 인자를 받을 수 있는데, 예를 들면 다음과 같다.
```
echo hello world
```
위를 입력하면 터미널에는 hello world 라고 출력된다. echo 뒤 인자는 문자열로 표시된다. 다만, 이것이 hello world 로 나오게 된 이유가 hello 와 world 사이 띄어쓰기 문자로 받아들여서 그런 것이 아니라, 두 개의 인자를 받아서 처리하는 방식이 그러하기 때문이다.

이를 잘 보여주기 위해서는 hello 와 world 사이를 길게 떨어뜨려보면 된다. 일반적으로 기대하는 값은 
```
hello               world
```
와 같이 길게 떨어진 형태이다. 하지만 놀랍게도 hello world 처럼 하나의 띄어쓰기만 포함된다. echo가 인자를 여러 개 받아서 처리한다는 증거이다. 그러면 띄어쓰기를 여러 개 넣고 싶으면 어떻게 해야 할까?
